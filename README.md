# zibll-ffqttg

子比主题前台投稿资源下载模块。

## 功能

- 在前台投稿页增加资源下载设置。
- 保留主题原有付费内容设置，并默认折叠。
- 支持多个资源条目。
- 每个资源支持下载链接、提取码、解压码。
- 支持评论可见、登录可见、VIP1 及以上可见、付费后可见。
- 资源显示在文章正文上方。
- 提取码和解压码支持点击复制。
- 复用子比主题原生隐藏内容权限逻辑。

## 安装

1. 将 `zibll-ffqttg` 目录复制到 WordPress 的 `wp-content/plugins/`。
2. 在 WordPress 后台启用“Zibll 前台资源下载模块”。
3. 确认当前启用的是子比主题，并且已开启前台投稿。

插件只在子比主题前台投稿页面加载投稿资源表单；文章页会读取插件保存的资源数据并输出下载模块。

## 使用

登录后打开前台投稿页面，在“资源下载设置”中添加资源。每个资源可单独选择可见权限：

- 评论后可查看
- 登录后可查看
- VIP1 及以上可查看
- 付费后可查看

选择“付费后可查看”时，需要同时配置子比主题原生付费内容。

## 数据

资源保存到文章 Meta：

```text
_zibll_ffqttg_download_resources
```

下载链接只允许使用 `http` 或 `https` 地址。插件不接管主题文章状态、审核、付费价格、附件上传或 Zibpay 下载流程。

## 兼容范围

- WordPress 前台投稿页面模板：`pages/newposts.php`
- 子比主题原生投稿 Ajax：`posts_save`、`posts_draft`
- 子比主题原生隐藏内容权限：`reply`、`logged`、`vip1`、`payshow`
